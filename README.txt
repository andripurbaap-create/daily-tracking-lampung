DAILY TRACKING LAMPUNG — UNSTOPPABLE 2.0

UPLOAD KE GITHUB PAGES:
1. Buat repository baru: daily-tracking-lampung
2. Upload 5 file ini ke root repository:
   - index.html
   - manifest.webmanifest
   - apple-touch-icon.png
   - icon-192.png
   - icon-512.png
3. Settings > Pages > Deploy from a branch > main > /(root) > Save.
4. Buka URL GitHub Pages melalui Safari iPhone.
5. Share > Add to Home Screen > nama: Daily Tracking > Add.
6. Hapus shortcut lama berikon D terlebih dahulu.
